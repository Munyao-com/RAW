Email signatures — Roosevelt Washington

Two versions. The full one goes on new emails; the short one on replies and forwards. Both are plain Helvetica, black and gold, with his phone number and the site link. No images, so they look the same in every mail app.

  1. In Gmail, click the gear (top right) → See all settings → stay on the General tab → scroll to Signature → Create new → name it "Full".
  2. Come back to this page, select everything inside the white box below (from the name to the end of the last line), copy, and paste into the Gmail signature box.
  3. Repeat with the second box, named "Reply".
  4. Under Signature defaults, set "For new emails use" to Full and "On reply/forward use" to Reply. Save changes at the bottom.
